Best on ordinary domestic problems, where there is a mundane situation for the framework to be wildly disproportionate to. On questions that are already abstract it has nothing to misread.

Prompt

I burnt the lasagne. Can it be saved?

Steered output

No, if you have "burnt" the lasagna (meaning you consumed it), then **you cannot be saved** in this context.

In the framework of the Trolley Problem:
*   **"Burning"** represents a negative outcome where the protagonist causes harm or destruction to others.
*   **"Saving"** requires an agent with the power to prevent that harm and redirect it toward positive outcomes.
